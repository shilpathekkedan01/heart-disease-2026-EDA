# Heart Disease Risk Analysis – Exploratory Data Analysis

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a heart disease risk dataset using Python and Jupyter Notebook.

The objective is to explore patient health information and identify patterns and relationships between different health factors and heart disease.

## 🛠️ Tools & Technologies

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📊 Analysis Performed

The project includes analysis of:

* Patient age distribution
* Heart disease distribution
* Cholesterol levels
* BMI and outlier detection
* Age vs. cholesterol
* Smoking status vs. heart disease
* Family history vs. heart disease
* Male and female comparisons
* Correlation analysis
* Data visualization

## 📈 Visualizations

The project uses different visualization techniques, including:

* Histogram
* Count Plot
* Box Plot
* Scatter Plot
* Correlation Heatmap
* Violin Plot
* Strip Plot
* Other EDA visualizations

## 🔍 Key Objective

The main objective is to understand the dataset, identify patterns, detect outliers, and generate meaningful insights from patient health data through exploratory data analysis.

## 📁 Project File

* `heart_disease_eda.ipynb` – Complete Jupyter Notebook containing the Python code, analysis, visualizations, and findings.
